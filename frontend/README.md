# Crickcast — frontend

React + Vite + Tailwind single-page app for the Crickcast live win-probability
tracker. See the [project root README](../README.md) for the full picture —
the ML pipeline, the backend, and how everything fits together.

## What's here

- A live ball-by-ball match simulator (undo, quick-start scenarios, a
  ball-by-ball scorecard strip)
- Real team selection, backed by `public/team_priors.json` (generated by
  the backend's data pipeline — see the root README's "Retraining the
  pipeline" section)
- Real-time win-probability display, a probability evolution chart, and
  live commentary from the backend's `/explain` endpoint
- A model insights section (calibration curve, event-impact chart,
  feature importance) — the PNGs and JSON files in `public/` are
  generated by the pipeline, not committed as hand-authored assets, and
  need re-copying here after every retrain

## Running locally

```bash
npm install
npm run dev
```

The dev server expects the backend running at `http://127.0.0.1:8000`
by default (see the root README's "Running locally" section) — this is
`vite.config.js`'s dev-server proxy target. Set `VITE_API_BASE_URL` in a
`.env` file here to point at a different backend (e.g. the deployed
Render instance); `src/App.jsx` reads it via `import.meta.env.VITE_API_BASE_URL`.
